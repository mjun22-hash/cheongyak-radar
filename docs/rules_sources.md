# 청약 자격 규칙 출처

조사 기준일: 2026-11-10. 법령과 API는 변경될 수 있으므로 실제 신청 전 공고문과 청약홈 순위확인서를 다시 확인한다.

## 적용 원칙

- 판정 기준일은 각 입주자모집공고일이다. 오늘 날짜로 통장·거주·무주택기간을 계산하지 않는다.
- API에 소득·자산·재당첨·지역우선·전매·거주의무 요건이 모두 구조화되어 있지 않으면 `⚠️ 확인 필요`로 판정한다.
- 소득·자산 한도는 연도·공급유형·단지마다 달라 공고문에서 확인된 값만 사용한다.
- 법령과 공고문이 충돌하면 해당 공고문에 적용된 시행일·경과조치부터 확인한다.

## 공식 법령

1. [주택공급에 관한 규칙 — 현행법령](https://www.law.go.kr/법령/주택공급에관한규칙)
   - 2026-06-15 시행, 국토교통부령 제1592호.
   - 제27조: 국민주택 일반공급. 수도권 1순위의 기본 통장기간·납입횟수.
   - 제28조: 민영주택 일반공급. 수도권 1순위, 가점·추첨 구조 및 무주택자 추첨 우선.
   - 제41조: 신혼부부 특별공급.
   - 제43조: 생애최초 특별공급. 단독세대주는 전용 60㎡ 이하로 제한되며 소득·자산·소득세 요건을 함께 확인해야 한다.
   - 제46조: 노부모부양 특별공급.
   - 제53조: 주택소유 여부 판정의 예외.

2. [주택공급에 관한 규칙 별표 1 — 가점제 적용기준](https://www.law.go.kr/LSW/flDownload.do?flNm=%5B%EB%B3%84%ED%91%9C+1%5D+%EA%B0%80%EC%A0%90%EC%A0%9C+%EC%A0%81%EC%9A%A9%EA%B8%B0%EC%A4%80%28%EC%A0%9C2%EC%A1%B0%EC%A0%9C8%ED%98%B8+%EA%B4%80%EB%A0%A8%29%0A&flSeq=69863649)
   - 미혼 신청자의 가점제 무주택기간은 원칙적으로 만 30세부터 기산한다. 30세 전 혼인 시에는 혼인신고일부터 계산한다.

3. [공공주택 특별법 시행규칙 — 현행법령](https://www.law.go.kr/법령/공공주택특별법시행규칙)
   - 공공분양의 공급유형별 선정 기준은 별표 6 등과 개별 공고문을 함께 확인한다.

## 공식 API

1. [한국부동산원 청약홈 분양정보 조회 서비스](https://www.data.go.kr/data/15098547/openapi.do)
   - 개발계정 일 40,000회, JSON/XML, 실시간 갱신.
   - APT 분양정보와 APT 잔여세대 정보를 1차 수집 범위로 사용한다.
   - `getAPTLttotPblancDetail`, `getAPTLttotPblancMdl`, `getRemndrLttotPblancDetail`, `getRemndrLttotPblancMdl`을 사용한다.

2. [한국부동산원 기술문서 — 청약홈 분양정보 조회 서비스(2026-01-29 수정)](https://www.reb.or.kr/reb/na/ntt/selectNttInfo.do?mi=10251&bbsId=1268&nttSn=79889)
   - 2026-01-29 주택명·공급위치 요청항목 추가, 2025-04-17 오퍼레이션 명칭 및 공급지역코드 변경 이력을 확인했다.

3. [국토교통부 아파트 매매 실거래가 상세 자료](https://www.data.go.kr/data/15126468/openapi.do)
   - 법정동 앞 5자리와 계약년월로 조회한다. 실거래 신고자료이며 계약일과 신고·공개 시점에는 시차가 있을 수 있다.
   - 최근 6개월, 유사 전용면적 거래가 3건 이상일 때만 ㎡당 중간값을 이용해 시세차익을 추정한다.

4. [국토교통부 실거래가 공개시스템](https://rt.molit.go.kr/)
   - 거래 공개 범위와 신고시점 차이 확인용 공식 안내.

## 구현에 넣지 않은 추정

- 규제지역 여부, 지역우선 비율, 예치금, 소득·자산 한도, 소득세 납부 이력, 재당첨 제한, 전매제한, 거주의무는 API 공통 필드만으로 확정하지 않는다.
- 자동차가액이 없거나 납입 인정금액·횟수가 사용자 추정이면 `미확인`으로 취급한다.
- 공고문 PDF 파싱이 없는 1단계에서는 `✅ 신청 가능`이 드물 수 있다. 이는 의도된 보수적 동작이다.
